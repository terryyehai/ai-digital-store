## 剪輯節奏指南

### 速度建議

| 段落 | 剪輯頻率 | 時長 |
|------|----------|------|
| Hook | 0-1 秒/鏡頭 | 0-3 秒 |
| 主內容 | 1-2 秒/鏡頭 | 3-25 秒 |
| 結尾 | 1 秒/鏡頭 | 3-5 秒 |

### 音效時間點

```
0:00 - 背景音樂開始
0:00 - 鉤子文字彈出
0:03 - 第一次節拍同步
0:10 - 節奏變化
0:25 - 結尾呼籲
0:28 - 淡出
```

## 文字設計

### 字體風格

```
標題：大字粗體 + 輪廓線 + 陰影
內文：中等大小 + 對比色
強調：閃爍/彈跳動畫
```

### 顏色

```
主要：白色 (#FFFFFF)
輪廓：黃色 (#FFD700) 或 紅色 (#FF0000)
陰影：黑色 (#000000)
```
