# 🎯 ChatGPT Prompt Cheat Sheet

## 用途
完整的 ChatGPT 提示詞技巧手冊，提升 AI 輸出質量 10 倍

## 內容目錄

### 第一章：基礎技巧

#### 1.1 角色設定 (Role Setting)
```
錯誤示範：
寫一篇關於行銷的文章

正確示範：
你是一位有 10 年經驗的 B2B 數位行銷顧問，專精於 SaaS 產業。
請撰寫一篇深入淺出的文章，主題是「B2B SaaS 公司如何透過內容行銷獲取企業客戶」。
目標讀者是中小型企業的行銷主管。
請使用專業但易懂的語調，包含實際案例和可執行的建議。
```

#### 1.2 結構化輸出 (Structured Output)
```
使用 Markdown 標題和列表
明確指定輸出格式
要求 JSON 或表格格式
```

#### 1.3 上下文提供 (Context)
```
背景資訊
約束條件
參考資料
預期結果
```

### 第二章：進階技巧

#### 2.1 思維鏈 (Chain of Thought)
```
讓 AI 展示思考過程
分步驟解決問題
要求解釋推理
```

#### 2.2 Few-Shot Learning
```
提供 2-3 個範例
範例要多元化
說明預期格式
```

#### 2.3 迭代優化 (Iterative Refinement)
```
第一版：基礎輸出
第二版：加入細節
第三版：優化結構
```

### 第四章：高效提示詞庫

| 類別 | 提示詞 | 應用場景 |
|------|--------|---------|
| 總結 | "用 3 個要點總結以下內容" | 快速理解長文 |
| 翻譯 | "翻譯成 [語言]，保持專業語調" | 專業翻譯 |
| 比較 | "從 [標準1]、[標準2] 比較 A 和 B" | 決策輔助 |
| 頭腦風暴 | "列出 10 個創意想法，要求原創且可行" | 創意生成 |
| 角色扮演 | "假設你是 [角色]，回答以下問題" | 模擬練習 |

### 第五章：常見錯誤避免

1. ❌ 提示詞太模糊
2. ❌ 缺少上下文
3. ❌ 沒有指定格式
4. ❌ 期望一次就完美
5. ❌ 不使用角色設定
