# 💼 Business Email Prompt Pack

## 用途
生成專業的商業郵件，提升溝通效率

## Prompt 列表

### 1. Cold Outreach Email
```
你是一位專業的 B2B 銷售專家。你的任務是撰寫一封能產生高回應率的 cold outreach 郵件。

## 目標受眾
[描述理想客戶畫像]

## 產品/服務
[輸入產品或服務描述]

## 要求
1. 開場白：引起興趣但不推銷
2. 價值主張：清楚說明能解決的問題
3. 社會證明：加入相關數據或案例
4. 行動呼籲：明確的下一個步驟
5. 簽名：專業但親和

## 輸出
請產出一封 150-200 字的郵件，語調專業但親和，適合首次聯繫潛在客戶。
```

### 2. Follow-Up Email
```
撰寫一封 follow-up 郵件，用於：
- 背景：[之前的互動情況]
- 目標：[這封郵件的目的]

要求：
- 簡短（100字以內）
- 提醒價值
- 明確 CTA
```

### 3. Meeting Request Email
```
 создайте一封預約會議的郵件：
- 目標人物：[姓名/職位]
- 會議主題：[主題]
- 建議時間：[時間範圍]
- 會議時長：[分鐘]
```

### 4. Proposal Email
```
撰寫一封提案郵件：
- 客戶名稱：[名稱]
- 問題/需求：[描述]
- 解決方案：[你的方案]
- 報價：[價格]
- 預期結果：[客户将獲得的價值]
```

### 5. Thank You Email
```
撰寫感謝郵件：
- 場合：[會議後/購買後/合作後]
- 關鍵內容：[需要感謝的重點]
- 未來行動：[下一步]
```
