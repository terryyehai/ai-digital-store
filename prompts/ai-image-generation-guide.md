### 第一章：基礎概念

#### 1.1 提示詞結構
```
[主體] + [環境] + [風格] + [光線] + [構圖] + [質量]

示例：
一位穿著宇航服的美女，在火星殖民地，日落時分，電影級畫質，寬幅構圖，電影光線
```

### 第三章：進階技巧

#### 3.1 負面提示詞
```
lowres, bad anatomy, bad hands, text, error, missing fingers, 
extra digit, fewer digits, cropped, worst quality, low quality, 
normal quality, jpeg artifacts, signature, watermark
```

#### 3.2 參數設置
```
--ar 16:9 (寬高比)
--v 6 (版本)
--s 750 (風格強度)
--iw 0.6 (圖像權重)
--no (負面提示)
```

#### 3.3 風格參考
```
--style photorealistic
--style anime
--style expressive
--style documentary
```
