## 3. RTP 計算

### 3.1 理論 RTP

```
假設均勻分佈：
- 每軸每符號出現率 = 權重/總權重
- 5連線機率 = (權重/100)^5 × 50條線
```

| 符號 | 預期回報 |
|------|----------|
| Gold | 0.05^5 × 50 × 100 = 0.003125 |
| Bronze | 0.08^5 × 50 × 50 = 0.000819 |
| ... | ... |
| **總 RTP** | **96%** |

### 3.2 RTP 分配

| 遊戲階段 | RTP 貢獻 |
|----------|----------|
| Base Game | 85% |
| Free Game | 11% |
| **合計** | **96%** |

## 4. 獎金計算公式

### 4.1 基礎公式

```
獎金 = 押注 × 支付線數 × 符號倍率 × 遊戲狀態倍率

遊戲狀態倍率：
- Base Game: 1x
- Free Game: 2x
```

### 4.2 示例

```
押注: 1元
押注線: 50條
中獎: Gold x5 (100x)
結果: 1 × 50 × 100 × 1 = 5000元
```
