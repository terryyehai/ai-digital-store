## 1. 歌曲結構 (Song Structure)

### 1.1 經典結構

| 結構 | 縮寫 | 說明 |
|------|------|------|
| Intro | intro | 前奏，設定情緒 |
| Verse | V | 主歌，敘述故事 |
| Pre-Chorus | Pre | 過渡，累積張力 |
| Chorus | C | 副歌，最高潮部分 |
| Bridge | B | 橋段，轉調或變化 |
| Outro | outro | 尾奏 |

### 1.2 常見結構模式

```
經典流行:
Intro → Verse → Pre-Chorus → Chorus → Verse → Chorus → Bridge → Chorus → Outro

簡單結構:
Verse → Chorus → Verse → Chorus → Chorus

32-bar form:
A → A → B → A (重複)

常規結構:
Intro → Verse1 → Chorus → Verse2 → Chorus → Bridge → Chorus → Outro
```

### 1.3 各段落時長

| 段落 | 時長 |
|------|------|
| Intro | 4-8 小節 |
| Verse | 8-16 小節 |
| Pre-Chorus | 4-8 小節 |
| Chorus | 8-16 小節 |
| Bridge | 4-8 小節 |
| Outro | 4-8 小節 |

## 2. 和弦進行 (Chord Progressions)

| 名稱 | 和弦 | 情緒 |
|------|------|------|
| I-V-vi-IV | C-G-Am-F | 流行經典 |
| I-IV-V-I | C-F-G-C | 明亮力量 |
| ii-V-I | Dm-G-C | 爵士經典 |
| I-vi-IV-V | C-Am-F-G | canon 進行 |
| vi-IV-I-V | Am-F-C-G | 悲傷流行 |

## 3. 旋律寫作 (Melody Writing)

### 3.1 旋律輪廓 (Contour)

| 類型 | 說明 | 範例 |
|------|------|------|
| 上升 | 能量增加 | C4→G4 |
| 下降 | 放鬆結束 | G4→C4 |
| 波浪 | 起伏平衡 | 上下波動 |
| 水平 | 穩定持續 | 同一音高 |

### 3.2 音程選擇

| 音程 | 效果 |
|------|------|
| 小二度 | 緊張、戲劇 |
| 大二度 | 溫和移動 |
| 大三度 | 溫暖、快樂 |
| 純四度/五度 | 力量、開放 |
| 八度 | 戲劇性對比 |

### 3.3 旋律公式

```
記憶點公式:
1. 重點音符在強拍
2. 音程跳躍後反向進行
3. 重複動機 + 變化
4. 結束在主音

鉤子法則 (Hook):
- 易於記憶的節奏
- 獨特的音程
- 重複但不無聊
```

### 3.4 旋律類型

| 類型 | 描述 |
|------|------|
| 級進旋律 | 相鄰音級進，平滑流暢 |
| 跳躍旋律 | 大音程跳躍，戲劇性 |
| 混合旋律 | 兩者結合，最常見 |

## 4. 節奏與Groove

### 4.1 節奏型

| 風格 | Pattern |
|------|---------|
| Pop | X . . X . . X . |
| Rock | X . . X . . X X |
| Funk | X . X . X . X . |
| Jazz | X . . X . X . . |
| Hip-hop | X . . X . . . X |

### 4.2 Groove 原則

```
1. 節奏放在正確的拍子上
2. 16分音符的位置創造feel
3. 切分音增加groove感
4. 動態對比
```

## 5. 編曲原則 (Arrangement)

### 5.1 頻譜分配

| 頻段 | 主要樂器 |
|------|----------|
| 低頻 (20-250Hz) | 貝斯、底鼓、腳鼓 |
| 中低 (250-500Hz) | 吉他、弦樂 |
| 中頻 (500-2kHz) | 人聲、鋼琴 |
| 中高 (2-4kHz) | 弦樂、合唱 |
| 高頻 (4-20kHz) | 銅鈸、合成器 |

### 5.2 層次原則

```
Verse: 
- 主旋律 + 節奏組 + 鋼琴/吉他

Pre-Chorus:
- 增加弦樂
- 增加鼓組力度

Chorus:
- 完整編制
- 所有元素

Bridge:
- 減少元素
- 新和弦進行
```

### 5.3 動態控制

| 段落 | 動態 |
|------|------|
| Intro | 輕，逐漸增加 |
| Verse | 中低 |
| Pre-Chorus | 逐漸增加 |
| Chorus | 高 |
| Bridge | 低或最高 |
| Outro | 逐漸減少 |

## 6. 音樂風格特點

### 6.1 Pop

```
BPM: 100-130
和弦: I-V-vi-IV
結構: Verse-Chorus 重複
特點: 鉤子旋律、易記
```

### 6.2 Electronic

```
BPM: 120-150
和弦: 簡單重複
結構: Build-up → Drop
特點: 節奏主導、合成器
```

### 6.3 Jazz

```
BPM: 80-140
和弦: ii-V-I、extensions
結構: 即興為主
特點: 複雜和聲、swing節奏
```

### 6.4 Classical/Cinematic

```
BPM: 60-120
和弦: 完整和聲進行
結構: 動機發展
特點: 動態對比、弦樂
```

## 7. 創作流程

### 7.1 靈感來源

```
1. 和弦進行 → 旋律
2. 節奏 → 旋律
3. 歌詞 → 旋律
4. 動機 → 發展
```

### 7.2 創作步驟

```
Step 1: 確定情緒/風格
Step 2: 選擇和弦進行
Step 3: 寫主旋律
Step 4: 設計節奏
Step 5: 編曲配器
Step 6: 動態調整
Step 7: 混音後製
```
