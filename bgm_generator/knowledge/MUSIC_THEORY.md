## 1. 鋼琴音色科學

### 1.1 鋼琴聲音的物理特性

| 特性 | 說明 | 數值 |
|------|------|------|
| **諧波結構** | 鋼琴有豐富的諧波 | 基頻 + 2~8 次諧波 |
| **諧波衰減** | 高頻諧波衰減較快 | 指數衰減 |
| **擊弦噪音** | 琴鎚擊弦的機械噪音 | 攻擊前 5-10ms |
| ** 共鳴** | 琴弦與音板的共振 | 持續整個音符 |

| 諧波序號 | 頻率倍數 | 相對音量 | 衰減速度 |
|----------|----------|----------|----------|

| H3 | 3x | 25% | 快 |
| H4 | 4x | 12% | 很快 |
| H5 | 5x | 6% | 很快 |
| H6 | 6x | 3% | 極快 |

| H8 | 8x | 0.8% | 極快 |

### 1.3 ADSR 包絡參數

| 參數 | 鋼琴數值 | 說明 |
|------|----------|------|
| Attack | 5-10ms | 快速起音 |
| Decay | 100-200ms | 快速衰減 |

## 5. 音頻驗證標準

### 5.1 鋼琴驗證清單

```python
PIANO_VERIFICATION = {
    "fundamental_freq_range": (60, 2000),  # Hz
    "spectral_centroid_range": (500, 3000),  # Hz
    "min_harmonics": 4,
    "attack_time_ms": (5, 20),
    "harmonic_decay": "exponential",
}
```

### 5.2 驗證流程

1. **FFT 分析** → 獲取頻譜
2. **找基頻** → 頻譜峰值
3. **計算諧波比** → 驗證諧波存在
4. **包絡分析** → 驗證 ADSR
5. **頻譜重心** → 驗證音色亮度

## 6. 鋼琴音色合成黃金法則

### 6.1 必須遵守

| 規則 | 說明 |
|------|------|
| ✅ 8層諧波 | 基頻 + 2~8 次諧波 |
| ✅ 諧波衰減 | 高頻諧波幅度遞減 |
| ✅ 鍵擊噪音 | 攻擊時的機械聲 |
| ✅ 快速起音 | 5-10ms |
| ✅ 指數釋音 | 自然衰減 |

### 6.2 禁止犯錯

| 錯誤 | 後果 |
|------|------|
| ❌ 單一正弦波 | 聲音像電子音 |
| ❌ 無諧波 | 聲音空洞 |
| ❌ 無噪音 | 不像鋼琴 |
| ❌ 起音太慢 | 聲音模糊 |
